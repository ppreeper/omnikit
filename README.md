# omnikit

Web Based Common Tools

OmniKit is a planned self-hosted web application offering a broad catalogue of everyday tools: text, data, encoding, developer utilities, dates, numbers, network, design, lists, images, video, audio and PDF. Core tools run entirely in the browser, with no uploads and no accounts required.

## Status

Planning and specification. The canonical catalogue contains 199 tool outcomes, derived from 233 tool instances across three anonymised reference products. Release 1.0 targets 33 P0 outcomes; complete parity is planned across releases 1.1 and 1.2.
